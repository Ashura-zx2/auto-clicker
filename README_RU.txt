POCO AUTO CLICKER — Android-проект (исходный код)

Возможности текущего MVP:
- Плавающая панель через AccessibilityService.
- Настройка целевой скорости 1–1000 CPS.
- Добавление координат касанием экрана через полноэкранный режим выбора.
- Последовательный клик по выбранным точкам.
- Счётчик завершённых жестов и приблизительная фактическая скорость.
- Старт/пауза, удаление последней точки, очистка списка.

Ограничения:
- Это ИСХОДНЫЙ ПРОЕКТ, а не собранный APK.
- Ползунок задаёт целевую скорость. Реальная скорость измеряется по завершённым Android-жестам и может быть значительно ниже.
- AccessibilityService.dispatchGesture асинхронен; Android/HyperOS и конкретные приложения ограничивают частоту. Нельзя гарантировать 400 или 1000 реальных CPS на POCO C75.
- В этой версии добавление точки перехватывает следующее касание экраном выбора. После выбора панель возвращается.
- Некоторые игры игнорируют синтетические жесты или запрещают автоматизацию. Не используйте для обхода античита/правил игры.

Сборка непосредственно на телефоне:
1. Установи AndroidIDE из официального источника.
2. Распакуй ZIP и открой папку PocoAutoClicker как Gradle-проект.
3. Дождись загрузки Gradle и SDK (проект использует AGP 8.7.3, Kotlin 2.0.21, compileSdk 35).
4. Собери debug APK через Build / Assemble Debug APK.
5. Установи APK.
6. В приложении разреши показ поверх окон и включи службу POCO Auto Clicker в настройках специальных возможностей.
7. После включения службы панель появляется автоматически. Выбери точку/точки и нажми Старт.

Для сборки потребуется интернет, чтобы AndroidIDE загрузил Gradle-плагины и Android SDK, если они ещё не установлены.


СБОРКА APK ЧЕРЕЗ GITHUB ACTIONS (можно с телефона, без ПК):
1. Создай новый репозиторий на github.com.
2. Распакуй этот ZIP на телефоне и загрузи ВСЕ файлы и папки проекта в репозиторий, сохранив структуру (включая скрытую папку .github).
3. Открой вкладку Actions в репозитории и разреши GitHub Actions, если попросит.
4. Выбери workflow "Build Android APK" и нажми Run workflow.
5. Дождись зелёной галочки завершения сборки.
6. Открой завершённый запуск workflow, внизу найди Artifacts и скачай poco-auto-clicker-debug.
7. Распакуй скачанный artifact ZIP — внутри будет app-debug.apk.

Если сборка завершится ошибкой, открой Build log и пришли скриншот последней ошибки.
